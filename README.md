# AURA Macro Pad 

**AURA** is a custom mechanical desktop controller designed for media navigation and other things basic need of our daily life. Built around a Raspberry Pi Pico, it brings together 6 tactile mechanical keys, an interactive OLED display, and a multi-function rotary encoder into a sleek, programmable package.

---

## Key Features

* **Microcontroller:** Powered by the Raspberry Pi Pico (RP2040) acting as a native USB HID keyboard and media controller.
* **Macro Matrix:** 6 mechanical keys (`SW2` through `SW7`) mapped to custom shortcuts.
* **Interactive OLED Display:** A 0.91-inch SSD1306 screen tracking song metadata (artist, track title, and progress bar) as well as active encoder modes.
* **Multi-Function Rotary Encoder (The Crown):** 
  * *Default:* Vertical scrolling.
  * *Shift + Rotate:* Horizontal scrubbing / zooming.
  * *Fn + Rotate:* System volume control.
  * *Push Switch:* Quick action trigger.
* **Smart Power-Saving:** Automatic 15-minute inactivity sleep timer to preserve screen life.
* **Dynamic Configuration:** Easily remap keys without rewriting firmware by editing a simple `config.json` file stored directly on the device.
* **Secure Enclosure Ready:** Integrated corner M3 mounting holes (`H1`–`H4`) for robust case assembly.
